Benchmark your agent

Clone DISPATCH and run the example in Node.js 22 or later. Replace its booking rule with your own. The runner gives each agent the current offer, posted forecast and revealed history. Use the same test shifts or select the retention and archive splits in the guide.

git clone --branch trust-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite trust --policy ./examples/reserve-agent.mjs --out trust.json
node tools/reserve.mjs --verify trust.json
