When empty travel paid off

Against the same agent with every Monday–Thursday overnight empty move converted to a wait, the learned rule earned +16.51 [+14.20, +18.81] credits per week and changed on-time service by +4.614 [+4.233, +4.995] percentage points.

A truck could move or stay on 4,157 of 8,192 Monday–Thursday nights. Both branches keep the same signed loads, decide one night differently, then follow the same learned rule through Friday. A week can contribute several nights.

How the comparison works

Two trucks work ten half-days across Harbor, Inland and Junction. The planner books the freight. On Monday through Thursday afternoons the trained policy can change where a spare truck spends the night. Every policy sees the current signed loads, past boards and Monday’s forecast. Missing a contract costs 34 credits. Net earnings deduct loaded mileage, empty mileage and missed-contract penalties.

Five agents trained independently. The release fit was fixed in advance. On fresh weeks the earnings test requires the lower bound of the paired 95% interval to exceed zero. Matching service requires the agent’s observed on-time rate to equal or exceed the planner’s, with a lower bound of at least zero percentage points on the paired difference. The retention test requires a positive lower earnings bound on new weeks from the original double-return schedule.

Benchmark your dispatcher

Run a JavaScript or Python policy on the same weeks. It receives the public board and legal moves and returns one joint move for the two trucks. The existing five-day fleet starters work here.

git clone --branch overnight-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite overnight --split validation --policy ./examples/fleetweek-agent.mjs --out validation.json
node tools/reserve.mjs --suite overnight --split test --policy ./examples/fleetweek-agent.mjs --out fresh.json
node tools/reserve.mjs --suite overnight --split archive --out returns.json -- python3 examples/fleetweek_agent.py
node tools/reserve.mjs --verify fresh.json
