Did predicting losses improve dispatch?

The loss-aware agent beat the rolling planner on fresh earnings. Its advantage over the constant penalty remains unproven. On 8,192 weeks across four unseen schedules, the agent earned 329.61 net credits per week. The constant penalty earned 329.73 and the rolling planner earned 329.03.

It matched both baselines on on-time service. The agent delivered 72.91% of contracts on time, compared with 72.73% for the planner. The double-return earnings win held. The archive contains 4,096 new weeks on the original double-return schedule.

How well did the agent spot losses?

1,637 of 1,647 forecasts fell in the 40%–60% range. Using a separate loss probability for each board changed 38 decisions compared with always using the training-calibration loss rate on those same boards.

On 1,647 eligible proposals the average predicted loss probability was 46.8%. In the paired simulator runs, 757 proposals lost (46.0%) and 6 tied. Each label compares the two moves under the same constant-penalty continuation.

The probability model’s Brier score was 0.2470. Always predicting the calibration loss rate of 47.0% scored 0.2485. This score averages squared probability error, so smaller values are better. Its AUROC was 0.539. That measures how often a loss receives a higher risk estimate than a non-loss, giving half credit for tied predictions. Random ordering averages 0.5.

How the comparison works

Two trucks work ten half-days between Harbor, Inland and Junction. Each dispatcher sees the same Monday forecast and the same orders as they arrive. Net earnings deduct loaded travel, empty travel and a 34-credit penalty per missed contract.

The earlier override agent proposes placements on Monday through Thursday afternoons. Each proposal keeps the same signed freight on the same trucks. The loss model learns from pairs of simulator runs that take different placements on the same afternoon and see the same freight through Friday.

The published constant-penalty agent charges the same risk penalty on every proposal. The new agent estimates each proposal’s probability of losing and the size of its possible gains and losses. A separate control uses the new model with one fixed loss probability, so you can measure what its individual probability estimates contribute.

The five registered comparisons use paired 95% intervals on weekly differences. For an earnings win, the lower bound must exceed zero credits. To match on-time service, it must reach zero percentage points. The agent faces both the planner and the published constant penalty on fresh weeks. The original double-return schedule has a separate earnings test against the planner.

Benchmark your dispatcher

Run a JavaScript or Python agent on the published weeks. It reads the public freight board and legal actions, then returns one joint move for the two trucks. Existing five-day fleet agents use the same interface.

git clone --branch loss-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite loss --split validation --policy ./examples/fleetweek-agent.mjs --out validation.json
node tools/reserve.mjs --suite loss --split test --policy ./examples/fleetweek-agent.mjs --out fresh.json
node tools/reserve.mjs --suite loss --split archive --out returns.json -- python3 examples/fleetweek_agent.py
node tools/reserve.mjs --verify fresh.json
