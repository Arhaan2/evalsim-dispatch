Benchmark your agent

Run your own JavaScript or Python dispatcher on the same shifts. Start on validation, then score the fresh test bank. Your dispatcher sees the price from wave one. After five offers, it returns buy or skip before it sees the sixth offer.

git clone --branch lastslot-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite lastslot --split validation --policy ./examples/lastslot-agent.mjs --out validation.json
node tools/reserve.mjs --suite lastslot --split test --policy ./examples/lastslot-agent.mjs --out test.json
node tools/reserve.mjs --verify test.json
