Benchmark your agent

Run your own JavaScript or Python dispatcher on the same shifts. At the survey window it receives five past offers and the price of the reading. It returns buy or skip before it sees the sixth offer.

git clone --branch paid-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite paid --policy ./examples/paid-agent.mjs --out paid.json
node tools/reserve.mjs --verify paid.json
