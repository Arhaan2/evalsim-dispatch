How the pilot works

One letter per decision
Qwen reads the orders, stock reports, freight in transit, and recent events. It selects one of up to eight typed calls labeled A–H. The menu supplies quantities and costs. The simulator executes the selected call.
What learns
The four-billion-parameter model stays frozen. A rank-4 adapter reads its final hidden state and adjusts the scores for the eight action letters. Training starts from the original model’s scores, with no supervised warm start.
72 training episodes
Each of 24 scenarios gets three sampled runs. A group-relative policy gradient updates the adapter using each run’s return relative to its two peers. Reward favors on-time arrivals and full completion, with deductions for spend and rejected calls.
20 paired test scenarios
The frozen model, final adapter, and hand-written dispatcher each face the same 20 fresh seeds. Four episodes per family cover closures, delays, demand surges, combined shocks, and a changed supplier network. This pilot uses one training seed.
