Did positioning save deliveries?

The release agent kept frozen fit 73’s dispatch on all 32,768 fresh weeks. The two fleets made the same deliveries and earned the same credits. They delivered 147 more contracts than the rolling planner. Their earnings lead of +0.019 credits/week had a 95% interval spanning zero.

The release agent passed 1 of four registered tests. Each required a positive lower 95% bound on paired whole weeks. The intervals resample complete weeks within each of the eight fresh freight schedules.

What changed in the other two fits?

Two independently trained fits did move the trucks. Fit 101 changed the depot arrangement on 1,038 warnings, delivered 76 more contracts than frozen fit 73 and earned +0.088 extra credits/week. Fit 211 changed the depot arrangement on 178 warnings, delivered 47 more contracts than frozen fit 73 and earned +0.053 extra credits/week. Both improved on fit 73 in service and earnings, and both improved on the rolling planner in service. Each fit’s earnings interval against the planner still spans zero. These secondary fits were fixed before the test.

Friday alone shows the trade-off. Fit 101 saved 35 contracts that fit 73 missed and missed 39 that fit 73 delivered. Fit 211 saved 12 contracts that fit 73 missed and missed 7 that fit 73 delivered. You can play one save and one miss from each fit on the warning board.

What the fitted values contributed

For each fit, the simulator replayed every legal warning dispatch on the same freight and repairs. The trucks then followed fit 73 from their new locations until Friday. Two learned values estimate future credits and signed deliveries. The agent can use the current trucks, freight, forecasts and public repair warning.

The primary fit trained on 22,528 weeks and compared 362,802 legal action branches. Fifteen service weights and switching thresholds were tested on independent selection weeks. Seed 73 was named for release before fitting. Once the warning passes, all fits use the frozen dispatcher.

A follow-up looked at the release fit’s warning times. All 8 changes on its selection weeks happened in the afternoon. It changed zero of 4,805 Tuesday, Wednesday or Thursday morning warnings. The fresh bank uses those three morning warnings.

Benchmark your dispatcher

Run your JavaScript or Python agent on the same weeks. Your agent sees the current freight, trucks and repair bulletin and can choose any legal dispatch.

Run a JavaScript or Python agent
git clone --branch preposition-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite preposition --split validation --policy ./examples/fleetweek-agent.mjs --out practice.json
node tools/reserve.mjs --suite preposition --split test --policy ./examples/fleetweek-agent.mjs --out fresh.json
node tools/reserve.mjs --suite preposition --split test --out python.json -- python3 examples/fleetweek_agent.py
node tools/reserve.mjs --suite preposition --split test --policy fit-101 --out fit101.json
node tools/reserve.mjs --verify fresh.json

Start with the validation bank, then choose test for fresh closure weeks, clean for ordinary weeks or archive for the original double-return schedule.
