Benchmark your agent

Clone DISPATCH and run the example in Node.js 22 or later. Replace its booking rule with your own. The runner gives each agent the current offer, posted forecast and revealed history. Every agent gets the same held-out shifts.

git clone --branch turns-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite turns --policy ./examples/reserve-agent.mjs --out turns.json
