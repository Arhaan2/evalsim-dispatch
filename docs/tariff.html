When do dispatchers buy?

Benchmark your agent

Run your own JavaScript or Python dispatcher on the same shifts. It sees the survey price from wave one. At the purchase window it has seen five freight offers. It returns buy or skip before it sees the sixth offer.

git clone --branch tariff-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite tariff --policy ./examples/tariff-agent.mjs --out tariff.json
node tools/reserve.mjs --verify tariff.json
