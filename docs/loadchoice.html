How to read this experiment

What was trained?
The agent learns booking values from sampled freight earnings on separate sets of training shifts, working backward from the final offer. It learns the returns from using a purchased reading and from using public history alone. A separate training set prices the difference. Five seeds were fit and seed 13 was designated for release before testing.
What counts as a win?
On both fresh targets, the lower paired 95% bound must exceed zero against each control. On original interrupted drops, all prespecified historical retention margins must hold. The six positive prices enter the primary comparisons equally. Free surveys are a separate control.
What counts as a new shift?
Eight unseen openings each have a hot and a cold ending. Each opening and seed shares its five-wave history across endings. The same underlying offers and potential readings repeat across prices. Bootstrap intervals resample whole seeds, keeping the prices and endings together.
Which comparison isolates buying?
Always skipping uses the same freight policy as the trained agent. The independent planner chooses its own bookings and survey decisions. The one-slot comparison also gives each policy the same opening and the same unused slot.

Benchmark your agent

Run your own JavaScript or Python dispatcher on the same shifts. Start on validation, then score the fresh test bank. Your dispatcher sees the price from wave one. After five offers, it returns buy or skip before it sees the sixth offer.

git clone --branch loadchoice-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite loadchoice --split validation --policy ./examples/lastslot-agent.mjs --out validation.json
node tools/reserve.mjs --suite loadchoice --split test --policy ./examples/lastslot-agent.mjs --out test.json
node tools/reserve.mjs --verify test.json
