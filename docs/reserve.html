Where does RL help?

The point planner reserves slots using each future offer’s mean. The distribution planner prices the option to wait using the full public probabilities. Q-learning learns the value of booking or waiting through practice.

Benchmark your agent

Clone DISPATCH and run the example in Node.js 22 or later. Replace its booking rule with your own. The runner gives every agent the same public observations and scores it on the same frozen shifts.

git clone https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --policy ./examples/reserve-agent.mjs --out my-result.json
