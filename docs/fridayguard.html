Training and evidence

Each fit trained on 180,224 simulated weeks and selected its settings on 90,112 separate weeks. At the closure warning it compared three frozen dispatchers’ moves. Three fitted tree models estimated the resulting changes in Friday pickups, full-week deliveries and net credits. After the warning, original fit 73 dispatched each fleet from its new positions.

Each Friday has two signed contracts. The benchmark pairs the same load, freight and repairs for each dispatcher. Its 95% intervals use 2,000 bootstrap draws that keep both Friday contracts within their original week and resample weeks within freight schedule.

Benchmark your dispatcher

Run your JavaScript or Python agent on the same weeks. Your agent sees the current freight, trucks and repair bulletin and can choose any legal dispatch.

Run a JavaScript or Python agent
git clone --branch fridayguard-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite fridayguard --split validation --policy ./examples/fleetweek-agent.mjs --out practice.json
node tools/reserve.mjs --suite fridayguard --split test --policy ./examples/fleetweek-agent.mjs --out fresh.json
node tools/reserve.mjs --suite fridayguard --split test --out python.json -- python3 examples/fleetweek_agent.py
node tools/reserve.mjs --verify fresh.json

Start with the validation bank, then choose test for fresh closure weeks, clean for ordinary weeks or archive for the original double-return schedule.
