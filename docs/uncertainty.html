Each replay comes from the middle of its group of helpful or costly decisions to accept or decline an override. Both branches see the same freight and follow the new agent after tonight.

Did turning down overrides pay?

The fresh weeks established neither an earnings advantage nor an on-time service match. Across 8,192 weeks from four unseen schedules, the agent earned 334.13 net credits per week and served 73.78% of its contracts on time. The rolling planner earned 333.69 credits and served 73.74%.

The double-return win held. On 4,096 new weeks from the original schedule, the agent earned 1.52 more net credits per week than the planner.

What did the uncertainty estimate change?

On the new agent’s path, the previous agent proposed changing the planner’s move on 1,626 of 32,768 overnight boards. The risk-aware agent accepted 1,246 proposals and kept the planner’s move on 380. Removing the downside penalty changed 266 decisions on those same boards. Replacing the individual estimates with one constant downside estimate changed 22 decisions. The paired weekly comparisons include the consequences through Friday.

How the comparison works

Two trucks work ten half-days between Harbor, Inland and Junction. Each dispatcher sees the same Monday forecast and the same orders as they arrive. Net earnings deduct loaded travel, empty travel and a 34-credit penalty per missed contract.

On Monday through Thursday afternoons, the previous override agent can propose a different placement for an empty truck. The new agent can accept that proposal or keep the rolling planner’s move. Both choices preserve each signed load and its assigned truck. The rolling planner handles the remaining rounds.

The release fit and the three tests were fixed before training. A win requires the lower end of the paired 95% earnings interval to exceed zero on both fresh weeks and the original double-return schedule. Matching service requires an on-time rate at least as high as the planner’s on fresh weeks, with the lower end of its paired interval at or above zero percentage points.

Benchmark your dispatcher

Run a JavaScript or Python agent on the published weeks. It reads the public freight board and legal actions, then returns one joint move for the two trucks. Existing five-day fleet agents use the same interface.

git clone --branch uncertainty-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite uncertainty --split validation --policy ./examples/fleetweek-agent.mjs --out validation.json
node tools/reserve.mjs --suite uncertainty --split test --policy ./examples/fleetweek-agent.mjs --out fresh.json
node tools/reserve.mjs --suite uncertainty --split archive --out returns.json -- python3 examples/fleetweek_agent.py
node tools/reserve.mjs --verify fresh.json
