Did the overrides pay?

The override agent earned 0.43 more net credits per week than the rolling planner. It served 72.70% of contracts on time, compared with 72.65% for the planner. Across the four unseen schedules, both the earnings advantage and the on-time match remained unproven.

On 2,048 fresh double-return weeks, the agent recovered a gain of 2.32 credits per week over the planner. The original fleet agent earned +5.07 and the earlier overnight agent earned +1.46 credits per week against the same planner on those weeks.

How the comparison works

Two trucks work ten half-days between Harbor, Inland and Junction. Each dispatcher sees the same Monday forecast and the same orders as they arrive. Net earnings deduct loaded travel, empty travel and a 34-credit penalty per missed contract.

On Monday through Thursday afternoons, the agent can change the planner’s empty-truck placement. Both choices give each signed load to the same truck. All other rounds follow the rolling planner.

The release fit and the three tests were fixed before training. A win requires the lower end of the paired 95% earnings interval to exceed zero on both fresh weeks and the original double-return schedule. Matching service requires an on-time rate at least as high as the planner’s on fresh weeks, with the lower end of its paired interval at or above zero percentage points.

Benchmark your dispatcher

Run a JavaScript or Python agent on the published weeks. It reads the public freight board and legal actions, then returns one joint move for the two trucks. Existing five-day fleet agents use the same interface.

git clone --branch override-v1.0.0 https://github.com/Arhaan2/evalsim-dispatch.git
cd evalsim-dispatch
node tools/reserve.mjs --suite override --split validation --policy ./examples/fleetweek-agent.mjs --out validation.json
node tools/reserve.mjs --suite override --split test --policy ./examples/fleetweek-agent.mjs --out fresh.json
node tools/reserve.mjs --suite override --split archive --out returns.json -- python3 examples/fleetweek_agent.py
node tools/reserve.mjs --verify fresh.json
